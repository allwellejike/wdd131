Website Planning Document

WDD 131: Dynamic Web Fundamentals

Site Name

Personal Technology Support & Learning Hub

This name was chosen because it clearly communicates the purpose of the website: providing support and learning resources for everyday technology use. The words “Support” and “Learning Hub” emphasize accessibility, guidance, and education for users with varying levels of technical experience.

Optional domain: techlearninghub.org

Site Purpose

The purpose of this website is to serve as an informational hub focused on everyday technology use and learning. The site will provide clear explanations of common technology services, beginner-friendly guides for web development using HTML, CSS, and JavaScript, tips for computer and mobile phone maintenance, and a contact or feedback section. JavaScript will be used to add interactivity such as form validation, dynamic content updates, and responsive navigation.

Scenarios

  • How can I learn the basics of HTML, CSS, and JavaScript as a beginner?
  • What are simple maintenance tips to keep my computer or mobile phone running smoothly?

Color Schema

The following colors were selected to create a clean, professional, and technology-focused design:

  • Primary Color (#1E3A8A – Deep Blue): Used for headings, navigation, and accents.
  • Secondary Color (#F1F5F9 – Light Gray): Used for backgrounds and content sections.

These colors provide strong contrast, improve readability, and support accessibility while maintaining a modern technology-oriented appearance.

Typography

  • Montserrat: Used for headings to create a bold and modern visual hierarchy.
  • Roboto: Used for body text to ensure readability and a clean user experience.

The selected fonts are web-safe, accessible, and suitable for both desktop and mobile devices.
